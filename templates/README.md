# Templates — Neoxix SOC Academy

Gabarits Markdown réutilisables pour documenter un laboratoire de façon cohérente à travers tous les domaines.

## Utilisation

Copier le template pertinent dans le dossier du laboratoire (`NN-Domaine/01-Labs/LAB-NN-Nom/`) et le renommer selon la convention en usage dans le domaine (ex. `README.md`, `Analysis.md`, `Evidence.md`).

## Index des templates

| Template | Usage |
| --- | --- |
| [LAB-README-TEMPLATE.md](./LAB-README-TEMPLATE.md) | Page d'entrée d'un laboratoire : contexte, objectifs, structure |
| [OBJECTIVES-SKILLS-TEMPLATE.md](./OBJECTIVES-SKILLS-TEMPLATE.md) | Objectifs techniques et compétences évaluées |
| [TOPOLOGY-INVENTORY-TEMPLATE.md](./TOPOLOGY-INVENTORY-TEMPLATE.md) | Topologie réseau et inventaire des équipements/hôtes |
| [CONFIGURATION-PROCEDURE-TEMPLATE.md](./CONFIGURATION-PROCEDURE-TEMPLATE.md) | Procédure de configuration pas à pas |
| [VALIDATION-PROCEDURE-TEMPLATE.md](./VALIDATION-PROCEDURE-TEMPLATE.md) | Procédure de validation / tests de bon fonctionnement |
| [TROUBLESHOOTING-TEMPLATE.md](./TROUBLESHOOTING-TEMPLATE.md) | Journal des problèmes rencontrés et solutions |
| [EVIDENCE-TEMPLATE.md](./EVIDENCE-TEMPLATE.md) | Preuves techniques (captures, exports, logs, hash) |
| [LESSONS-LEARNED-TEMPLATE.md](./LESSONS-LEARNED-TEMPLATE.md) | Leçons apprises et recommandations |

## Règle commune

Toute section nécessitant une exécution réelle non encore effectuée doit rester marquée :

```
TODO — À compléter pendant le laboratoire.
```

Voir [CLAUDE.md](../CLAUDE.md) pour les règles complètes sur les données de laboratoire.
