# Index des laboratoires

## Légende des statuts

| Statut | Signification |
| --- | --- |
| ⚪ Planned | Laboratoire défini mais non commencé |
| 🟡 In Progress | Laboratoire en cours de réalisation ou de documentation |
| 🟢 Completed | Laboratoire exécuté, documenté et validé |
