## Portée

Ce dossier documente le **fonctionnement du dépôt lui-même** (architecture, conventions, workflow). La documentation technique de chaque laboratoire vit dans son propre domaine (`NN-Domaine/01-Labs/...`), pas ici.

## Convention

- Un document par sujet, nommé en `MAJUSCULES-KEBAB-CASE.md` pour les documents de référence.
- Toute nouvelle décision structurante notable est consignée dans [adr/](./adr/README.md), pas seulement discutée en conversation.
