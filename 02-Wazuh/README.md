# 02 — Wazuh

## Objectif du domaine

Déployer et exploiter Wazuh comme plateforme SIEM/XDR open source : collecte d'événements, règles de détection, intégration Sysmon et analyse d'incidents simulés.

## Compétences visées

- Déploiement d'un Wazuh Manager et d'agents Windows/Linux.
- Intégration de Sysmon pour la télémétrie Windows.
- Écriture et test de règles de détection personnalisées.
- Analyse d'événements de sécurité et triage d'alertes.

## Prérequis

- Bases Linux (installation, services).
- Notions de journalisation Windows (Event Log, Sysmon).
- Domaine [00-Environment](../00-Environment/README.md) opérationnel.
