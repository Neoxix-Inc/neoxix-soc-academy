# Diagrams

Diagrammes transverses au dépôt entier (architecture globale, vue d'ensemble multi-domaines), par opposition aux diagrammes propres à un domaine ou à un laboratoire spécifique (ex. `01-Wireshark/05-Diagrams/`, `NN-Domaine/01-Labs/LAB-NN/Topology.drawio`).

## Convention

- Format `.drawio` de préférence, pour rester éditable.
- Nommer les fichiers par leur portée : `architecture-globale.drawio`, `flux-domaines.drawio`, etc.
