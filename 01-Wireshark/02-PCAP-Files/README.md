# 02 — PCAP Files

Fichiers de capture réseau bruts (`.pcap` / `.pcapng`) produits pendant les laboratoires du domaine [01-Wireshark](../README.md).

## Règles

- Aucune capture de trafic de production. Uniquement des captures issues d'un environnement de laboratoire isolé.
- Aucune donnée personnelle ou secret ne doit apparaître dans une capture publiée (voir [CLAUDE.md](../../CLAUDE.md)).
- Nommer les fichiers en lien avec le laboratoire d'origine, ex. `LAB-01-baseline-capture.pcapng`.
