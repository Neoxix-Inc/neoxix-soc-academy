# LAB-01 — Network Traffic Baseline

## Domaine

`01-Wireshark`

## Statut

🟡 In Progress

## Résumé

Établir une référence (baseline) de trafic réseau normal à l'aide de Wireshark, en préparation de la détection future de comportements suspects.

## Objectifs et compétences

### Objectifs techniques

- [ ] Capturer du trafic réseau normal dans un environnement de laboratoire isolé.
- [ ] Identifier les protocoles principaux présents dans la capture.
- [ ] Analyser les communications entre les hôtes du laboratoire.
- [ ] Créer une référence de trafic légitime (baseline).
- [ ] Préparer les bases de la détection de comportements suspects pour les laboratoires suivants.

### Compétences évaluées

| Compétence | Niveau visé |
| --- | --- |
| Capture de trafic avec Wireshark | Débutant |
| Filtrage d'affichage et de capture | Débutant |
| Identification de protocoles (TCP/IP, DNS, HTTP, ARP, ICMP) | Débutant / Intermédiaire |
| Établissement d'une baseline réseau | Intermédiaire |

## Prérequis

- Domaine [00-Environment](../../../00-Environment/README.md) opérationnel (labo réseau isolé).
- Wireshark installé sur la machine d'analyse.
- Notions de base TCP/IP.
